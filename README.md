# 🥼 LauraTerapia — Site de Fisioterapia

Projeto de desenvolvimento web criado com **HTML5 e CSS3**, com o objetivo de apresentar o site fictício de uma clínica de fisioterapia chamada **LauraTerapia**.

Além de ser uma oportunidade para praticar desenvolvimento web, este projeto possui um significado especial: foi inspirado na área profissional em que minha namorada, Laura, deseja atuar — a **Fisioterapia**.

---

## 🎯 Sobre o projeto

O LauraTerapia foi desenvolvido como um projeto de aprendizagem, buscando construir um site organizado, intuitivo e visualmente agradável para representar uma clínica de fisioterapia.

A proposta é apresentar informações sobre a clínica, seus tratamentos, profissionais e formas de contato, além de uma página de agendamento.

O projeto também representa uma forma de unir meus estudos na área de tecnologia com uma área profissional que é importante para alguém especial para mim.

## 📄 Páginas do projeto

O site é composto por seis páginas principais:

| Página | Descrição |
|---|---|
| **Início** | Apresentação da clínica LauraTerapia. |
| **Sobre** | Informações sobre a clínica e sua missão. |
| **Tratamentos** | Apresentação dos tratamentos fisioterapêuticos. |
| **Profissionais** | Apresentação da profissional. |
| **Agendamento** | Formulário para solicitação de agendamento. |
| **Contato** | Informações para entrar em contato com a clínica. |

## 🛠️ Tecnologias utilizadas

- HTML5 — estruturação das páginas.
- CSS3 — estilização e organização visual.
- Visual Studio Code — ambiente de desenvolvimento.
- Git e GitHub — versionamento e armazenamento do projeto.

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Localize o arquivo `index.html`.
4. Clique com o botão direito e selecione **Open with Live Server**, caso tenha a extensão instalada.

### Clonar o repositório

```bash
git clone https://github.com/jvalexandre30-pixel/Lauraterapia-HTML.git
```
